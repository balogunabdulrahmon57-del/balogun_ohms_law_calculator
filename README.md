# Ohm's Law and Power Calculator

## What it does

This Python program is an electrical calculator based on Ohm's Law.
It can calculate voltage, current, resistance and power using values
entered by the user.

## How to run it

Install Python 3, then run:

python ohms_law_calculator.py

## Sample output

Choose an option (1-4): 1
Enter current in amperes (A): 5
Enter resistance in ohms: 10
Voltage = 50.00 V

## My own twist

I added a repeat option so the user can perform several calculations
without restarting the program.
